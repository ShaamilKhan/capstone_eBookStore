Project Goal

The Objective

Move beyond theory and apply AI in a real development workflow using agentic IDE tooling, producing a production-grade application from wireframes to deployment.

Problem Statement

Modern engineering teams leverage AI-assisted development to accelerate delivery. This capstone bridges the gap between traditional development practices and AI-augmented workflows.

The task: build a production-grade e-commerce bookstore that demonstrates how agentic IDEs like IBM BOB can be used end-to-end — from wireframe analysis to deployment-ready code.

Project Goals
  • Design a normalized data model from UI wireframes
  • Generate OpenAPI specifications with agentic IDE
  • Build a complete Spring Boot REST backend with JWT auth
  • Develop a responsive React frontend with full CRUD flows
  • Implement AI-based book recommendations from order history
  • Write unit and integration tests using JUnit 5 and Mockito
  • Deploy locally and push to GitHub with a Pull Request

Customer Flow

User Journeys

Twelve end-to-end customer journeys implemented across the full application stack.

STEP 01
Landing Page
Hero banner, featured books grid, category cards, and entry points to the catalogue.
STEP 02
Login & Register
JWT-based auth. New users register with name, email, phone and password. Auto-login on register.
STEP 03
Select Category
Browse Fiction, Non-Fiction, Science, and Technology from the catalogue sidebar.
STEP 04
Browse Brands
Filter by publisher. Penguin Random House, HarperCollins, O’Reilly Media.
STEP 05
Product Catalogue
Paginated book grid with search, price range filter, and sort by price or rating.
STEP 06
Product Detail
Author, ISBN, pages, language, estimated delivery date, star rating, reviews, and related books.
STEP 07
AI Recommendations
Top-rated books in categories the user has purchased from before, excluding already-ordered titles.
STEP 08
Add to Cart
Quantity selection, live cart count badge in navbar, free shipping threshold at $30.
STEP 09
Delivery Address
Checkout step 1: select a saved address or add a new one with label, street, city, and country.
STEP 10
Payment
Credit card, debit card, or gift points. Masked card inputs. Sticky order summary sidebar.
STEP 11
Redeem Gift Points
Earn 1 pt per $1 spent. 100 pts = $1 off. Max redemption capped at 20% of order total.
STEP 12
Confirmation & Cancel
Order confirmation with points earned. Cancel within 48 hrs if PENDING or CONFIRMED — auto stock restore.
Core Capabilities

Key Features

Eight core systems powering the end-to-end bookstore experience.

🔑
JWT Authentication
Stateless auth with BCrypt hashing. Token in localStorage, injected on every request via Axios interceptor. Auto-logout on 401.
🔍
Dynamic Product Filtering
JPA Specification queries. Filter by category, brand, price range, keyword. Sort by price or rating. Server-side pagination.
🛒
Persistent Cart
Server-side cart in PostgreSQL. Survives browser refresh. Real-time subtotal, shipping, and item count badge in navbar.
💳
Multi-step Checkout
Address → Review → Payment. Progress bar. Credit/debit card form and gift points tab. Placed order deducts stock atomically.
⭐
Gift Points System
1 point per $1 spent. Redeem 100 pts for $1 off. Max 20% discount per order. Balance shown in profile and payment page.
🤖
AI Recommendations
Personalised suggestions from order history. Top-rated books in categories previously purchased, excluding already-bought titles.
📦
Order Lifecycle
PENDING → CONFIRMED → SHIPPED → DELIVERED. Buy Again in one click. Cancel within 48 hrs with full stock and points refund.
⭐
Reviews & Ratings
One review per user per book. Submission recalculates average product rating. Displayed on detail page with reviewer name and date.
